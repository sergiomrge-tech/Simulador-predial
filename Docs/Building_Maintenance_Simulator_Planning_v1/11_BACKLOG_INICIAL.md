## Definição de pronto para cada tarefa

Uma tarefa só é concluída quando:

- compila sem erro;
- funciona no build, não apenas no Editor;
- não quebra save;
- tem teste manual documentado;
- IDs persistentes estão definidos;
- nenhum asset temporário crítico fica perdido sem identificação.
