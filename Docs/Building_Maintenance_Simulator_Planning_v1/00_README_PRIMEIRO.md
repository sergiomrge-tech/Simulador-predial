# Projeto — Simulador de Manutenção Predial / Facilities

**Versão do planejamento:** 1.0  
**Data-base:** 03/10/2026  
**Plataforma-alvo:** PC / Steam  
**Engine principal:** Unity 6 LTS  
**Linguagem:** C#  
**Modo inicial:** Single-player  
**Modelo comercial inicial:** Premium

## Objetivo deste pacote

Este ZIP contém o planejamento completo inicial para desenvolver um jogo indie de simulação de manutenção predial/facilities em primeira pessoa, com foco comercial na Steam. O jogador começa como técnico autônomo, atende chamados simples e evolui até comandar uma empresa capaz de assumir contratos de grandes instalações.

O conceito central combina três pilares:

1. **Trabalho manual satisfatório** — localizar falhas, usar ferramentas, substituir componentes, limpar, ajustar, testar e concluir o serviço.
2. **Diagnóstico real de gameplay** — o jogador precisa descobrir a causa, não apenas seguir um marcador até um botão.
3. **Crescimento empresarial visível** — ferramentas melhores, van, oficina, estoque, funcionários, contratos, especializações e instalações maiores.

## Decisões já fechadas

- O projeto será desenvolvido para **PC/Steam**.
- A engine principal será **Unity**.
- O jogo será **3D em primeira pessoa**.
- O foco inicial será **single-player**.
- O jogo não será um clone de supermercado, carro, cafeteria ou loja genérica.
- O diferencial será a combinação entre **manutenção técnica + diagnóstico + progressão empresarial**.
- O primeiro build jogável será pequeno e profundo, com poucos sistemas bem resolvidos em vez de dezenas de mecânicas rasas.
- O nome comercial ainda não está fechado.
