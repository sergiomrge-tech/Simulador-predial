# Roadmap de Produção

## Regra geral

Não construir o jogo inteiro antes de validar o núcleo.

## Fase 0 — Pré-produção

Objetivos:

- fechar nome provisório interno;
- criar repositório;
- configurar Unity 6 LTS;
- definir convenções C#;
- criar estrutura de pastas;
- prototipar interação em primeira pessoa;
- definir pipeline de assets.

Saída:

- projeto abre limpo;
- personagem anda/interage;
- build Windows funciona.

## Fase 1 — Protótipo de diagnóstico

Criar uma sala técnica de teste.

Implementar:

- 1 sintoma;
- 3 causas possíveis;
- 2 ferramentas;
- coleta de evidências;
- diagnóstico;
- reparo;
- teste final.

Critério de sucesso:

O jogador entende o problema sem marcador revelando a solução.

## Fase 2 — Vertical slice

Conteúdo:

- prédio pequeno;
- hub básico;
- 3 famílias de falha;
- 5–8 missões;
- dinheiro;
- compra de peças;
- ferramentas;
- reputação;
- save/load;
- UI funcional;
- áudio básico.

Critério:

30–45 minutos de experiência coerente e divertida.

## Fase 3 — Alpha comercial

Adicionar:

- sede evolutiva;
- van;
- estoque;
- 20–30 chamados;
- contratos;
- 1 funcionário;
- elétrica + hidráulica + climatização básica;
- 3–4 locais;
- tutorial revisado.

Objetivo:

Primeiro build que poderia ser mostrado publicamente.

## Fase 4 — Demo Steam

Conteúdo selecionado, não jogo completo.

Objetivos:

- 45–90 minutos;
- progressão clara;
- final da demo com teaser de contratos maiores;
- telemetria local/opt-in se aplicável;
- página Steam otimizada;
- playtest externo.

## Fase 5 — Early Access ou lançamento 1.0

Decidir apenas após métricas da demo/wishlist.

### Se Early Access

Necessário:

- loop já divertido;
- conteúdo suficiente;
- roadmap público realista;
- saves estáveis e migráveis.

### Se lançamento direto

Necessário:

- campanha/progressão completa;
- quantidade robusta de falhas;
- polimento alto;
- localização principal.

## Fase 6 — Pós-lançamento

Expansões possíveis:

- elevadores;
- geradores;
- rede/telecom;
- instalações industriais;
- cooperativo somente se o jogo single-player justificar.

## Milestones sugeridos

### M0 — Technical Foundation
- movimentação;
- interação;
- item/tool system;
- save base.

### M1 — First Fix
- primeira falha diagnosticável completa.

### M2 — Service Loop
- missão → reparo → pagamento → hub.

### M3 — Vertical Slice
- 3 sistemas básicos.

### M4 — Company Growth
- upgrades + estoque + van + reputação.

### M5 — Content Alpha
- volume de missões.

### M6 — Steam Demo
- build público.

### M7 — Release Candidate
- conteúdo final + QA + otimização.

## Critérios de corte

Cortar ou adiar se ameaçar cronograma:

- direção veicular livre;
- mundo aberto;
- multiplayer;
- IA social complexa;
- construção livre de edifícios;
- clima totalmente dinâmico;
- física de fluidos real;
- simulação elétrica profissional.
