# PROJECT RESORT — Starter Visual Pack

Este diretório contém as referências visuais oficiais para o Claude iniciar a conversão do projeto para PROJECT RESORT.

## Ordem de uso

1. `01_PRAIA_SANTA_AURORA_QUIOSQUE_INICIAL.png`
   - referência principal do mundo inicial;
   - define praia, calçadão, via, bairro costeiro e implantação do quiosque.

2. `02_QUIOSQUE_OPERACAO_BALCAO.png`
   - referência do gameplay do balcão;
   - usar para caixa, geladeira, freezer, produtos, clientes e circulação.

3. `03_QUIOSQUE_ESTOQUE_REPOSICAO.png`
   - referência do lado de serviço;
   - usar para estoque, crates, recebimento, lixeira e reposição.

4. `04_CASA_INICIAL_JOGADOR.png`
   - referência da casa modesta do início;
   - usar no loop acordar → trabalhar → voltar → dormir.

5. `05_PRIMEIRA_POUSADA.png`
   - referência da primeira grande expansão;
   - NÃO construir antes do gate do quiosque e da expansão de terreno.

6. `06_RESORT_CINCO_ESTRELAS_NORTH_STAR.png`
   - referência aspiracional de endgame;
   - NÃO construir agora;
   - serve para preservar a direção de longo prazo.

## Hierarquia visual

Para a fase atual:

**01 > 02 > 03 > 04**

As imagens 05 e 06 são apenas referências de progressão futura.

## Regras

- são concept arts, não screenshots da Unity;
- não copiar rótulos/marcas visíveis;
- modelar objetos como assets próprios;
- respeitar escala humana e primeira pessoa;
- manter o quiosque inicial humilde;
- não antecipar luxo;
- usar materiais PBR coerentes;
- priorizar layout jogável e performance;
- capturas de gameplay futuras devem ser reais da Unity.
