# FASE 06 — VERTICAL SLICE DA POUSADA

## Objetivo

Introduzir hotelaria com um recorte pequeno e completo.

## Conteúdo

- pequena recepção;
- 4 quartos;
- reserva;
- check-in;
- quarto ocupado;
- limpeza;
- check-out;
- diária;
- avaliação;
- café da manhã simples;
- estacionamento pequeno.

## Hóspede

Fluxo completo:
reserva → chegada → recepção → quarto → consumo mínimo → dormir → check-out → avaliação.

## Gate

Receber múltiplos hóspedes por pelo menos três dias simulados, sem quebrar estoque, dinheiro, limpeza, reservas ou save.
