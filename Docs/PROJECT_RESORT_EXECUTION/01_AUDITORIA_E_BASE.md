# FASE 01 — AUDITORIA E CONSOLIDAÇÃO DA BASE

## Objetivo

Descobrir o estado real do projeto e consolidar a melhor base técnica para PROJECT RESORT.

## Executar

- identificar branch local e HEAD;
- listar mudanças não commitadas e arquivos não rastreados;
- verificar stash;
- comparar branches relevantes;
- localizar qualquer trabalho já iniciado de resort;
- mapear cenas, prefabs, scripts e assets reaproveitáveis;
- identificar conflitos entre documentação antiga e nova;
- definir a branch de produção do resort;
- preservar sistemas úteis do Facility Ops;
- isolar sistemas antigos que não sejam mais núcleo.

## Reaproveitar prioritariamente

- primeira pessoa;
- interação;
- CharacterController;
- portas;
- save;
- streaming;
- Santa Aurora;
- vias e terreno;
- casa;
- veículos;
- sistemas técnicos;
- pipelines Blender/Unity;
- validadores e testes.

## Entregáveis

- relatório de auditoria;
- mapa de sistemas reaproveitados;
- mapa de sistemas legados isolados;
- branch oficial confirmada;
- build/editor abrindo sem regressão.

## Gate

PASS somente quando o estado do projeto estiver conhecido, sem risco de sobrescrever trabalho e com uma base reproduzível para a fase 02.
