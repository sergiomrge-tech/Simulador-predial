# FASE 07 — CONSTRUÇÃO MODULAR

## Objetivo

Permitir que o jogador construa e expanda sem depender de cenas fixas.

## Implementar

- modo construção;
- grid/snap quando necessário;
- paredes;
- pisos;
- tetos;
- portas;
- janelas;
- corredores;
- mobiliário;
- demolição segura;
- custo de construção;
- persistência.

## Validação de quarto

Exigir:
- acesso;
- cama;
- iluminação;
- banheiro;
- privacidade.

## Gate

O jogador deve conseguir construir um novo quarto válido, salvá-lo, recarregar e hospedá-lo.
