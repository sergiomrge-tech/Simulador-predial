# FASE 05 — EXPANSÃO DE TERRENO

## Objetivo

Fazer a primeira expansão física do empreendimento.

## Implementar

- lote inicial;
- limites visíveis;
- lote adjacente;
- preço;
- requisito de reputação;
- compra;
- persistência;
- desbloqueio físico do espaço;
- preparação para pousada.

## Regra

A compra deve ser visível no mundo, não apenas um número em menu.

## Gate

Comprar o lote, salvar, recarregar e continuar com a nova área liberada.
